#  Projetos em Java ♨️

Bem-vindo ao meu repositório de projetos em **Java**!

Este repositório reúne os projetos, desafios e exercícios desenvolvidos durante meus estudos em Java. O objetivo é acompanhar minha evolução como desenvolvedor, praticar lógica de programação e aplicar conceitos aprendidos ao longo dos cursos e bootcamps.

## 📚 Tecnologias utilizadas

* Java
* IntelliJ IDEA
* Git e GitHub

## 📂 Estrutura do repositório

```text
Projetos-Java/
│
├── SimunDeliveryApp/
├── SmartTV/
├── SistemaBancario/
├── hierarquiaDeExceptionsExemple/
└── README.md
```

Cada pasta contém um projeto independente, com seu próprio código-fonte e documentação.

## 🎯 Objetivos

* Praticar lógica de programação.
* Aprender boas práticas de desenvolvimento.
* Desenvolver projetos cada vez mais completos.
* Construir um portfólio para acompanhar minha evolução.
